### Fixed — CI: the ffmpeg install survives a slow Ubuntu mirror (cached .debs, one retried download)

On 2026-11-19 the backend job failed four runs in a row at `Install ffmpeg`: DNS was fine and `apt-get update` worked, but one slow mirror stalled single packages of the 66 MB install until the 5-minute budget ran out. `scripts/ci-install-ffmpeg.sh` now downloads the `.deb` files first (`--download-only`, capped at 240 s and retried once with the rest of a 12-minute budget), then installs once from the complete directory, which `actions/cache` keeps between runs, so a slow mirror costs one run at most and later runs fetch only what changed. `apt-get update` keeps its own 300 s cap, so a DNS outage still fails fast with a clear error annotation. The backend job's timeout is now 25 minutes. The script's stub-based shell tests cover the split, the retry, the budgets and the cache notices.
