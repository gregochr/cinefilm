### Added — pick an OpenSubtitles file yourself, from Subtitles and To do (Admin redesign 4c)

"Search for English subtitles…" (or "It's in German — find subtitles" when the audio isn't labelled) on a foreign-language film, and "Find forced subtitles…" on an English film with foreign scenes, now open a list of what OpenSubtitles has for that film's edition, best match first as the server ranks it. Each file shows its release name, downloads, frame rate, whether a trusted uploader made it, whether it is for the hard of hearing and the year it was uploaded. "Use this file" downloads it, closes the list, and the film leaves the Subtitles tab and the To do group; the same buttons are on the To do rows. If OpenSubtitles says no, the list stays open with the server's own words (the daily limit, a scan running, a file that can't be used, an outage) and you can choose another file. Closing the list while a download is still running is safe: the file is still saved on the server and the page reads it again. The two need lists gain an `editionId` on each row (the film's first present edition) so the buttons know which edition to search for.
