### Changed — Admin cleanup, backend

A refused Admin change now says who holds the library lock: "A scan is running" only for a scan, and a plain
"try again in a moment" line for a Plex import, a match fix, an editions save, a subtitle change or check, or a credits
save. A film's file in Admin reads "a download you picked plays instead" when a pick beats an unchecked file. The Admin
summary no longer loads every edition for its full-subtitle figure, the grouping change log has an index on its time,
and the Continue watching range error is in plain words ("Continue watching needs at least 0 and at most 30 minutes").
