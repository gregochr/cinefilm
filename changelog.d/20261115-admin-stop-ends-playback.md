### Changed — Admin's Stop now ends playback on that device

Pressing "Stop this stream" in Admin's Playback section used to end only the server's conversion, and the player started a new one within seconds. Now the device stops: the player pauses, clears its picture and says "Playback was stopped from Admin." with a "Play again" button that starts a fresh playback from where it stopped. Stop on a row ends that row's own playback, never another device's playback of the same film. The server remembers the stop for 24 hours (in memory, so a restart forgets it) and answers 410 for that playback's session routes and for a new session under its viewing id. An expired session (404), a dropped connection, a server error and a server restart still recover exactly as before. The hint under Stop is the design's wording again: "Ends playback on {device}; it can resume from here". A player page that was already open from before this release shows "Reconnecting…" after a Stop until it is reloaded.
