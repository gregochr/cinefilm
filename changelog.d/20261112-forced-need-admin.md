### Added — Admin list of which films need forced subtitles

Admin → Subtitles has a new section, "Which films need them", above the file list. Chips show the films that need
forced subtitles and have none yet (the first view), the unsure, the unknown, the not needed, and all of them, each
with its count. Each film says why in plain words (for example "Also spoken: French, Russian (TMDB)") and has three
buttons, Needed, Not needed and Automatic, to set your own choice. The list is shown 100 films at a time, reads
again after a scan or when a subtitle file is attached, moved or detached, and a failed save says so beside the film.
