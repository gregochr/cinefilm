### Added — Full subtitles in Admin

Full English subtitles from OpenSubtitles now appear in the Subtitles panel like the forced ones: where they came from, a "Playing" tag when the film plays them, a plain sentence saying why a file is or is not used (for example "Playing as English (full); not checked yet" or "Not used: your own full file plays instead"), Remove with its confirmation, and the timing nudge. The file list has new Forced and Full chips, so you can see only the full files; the other chips still count forced files only. Each film in the full subtitles list says in one line what plays for it (your file, a download that is not checked yet, or none yet) and has a button that shows that film's full files. That list also now opens on Unsure when no film is needed, and on Not needed when none is unsure either, instead of on an empty Needed chip.
