### Changed — one CI workflow like goldenhour's

`backend.yml` and `frontend.yml` are replaced by a single `ci.yml` with the required checks `Backend — Build, Test & Coverage` and `Frontend — Lint, Test & Build`. Docs-only changes are detected inside the workflow (no `paths:` filters, so both checks always report), pull requests must cover at least 90% of their changed lines on both sides (diff-cover on JaCoCo XML and Vitest lcov), and the frontend job now runs `scripts/npm-audit.sh frontend high`. `ci-failure-issue.yml`, Dependabot (Maven, npm with a vitest group, GitHub Actions) and CineLight's label-then-merge Dependabot auto-merge for minor and patch updates (the repo is private, so there is no branch protection) are added. `CLAUDE.md` and `docs/engineering/dev-and-testing.md` now document the same commands CI runs.
