### Added — credits classifier: the embeddings run (L4b-3)

`CreditsEmbedMain` embeds every row of a features run with an image encoder and writes `embed-<stamp>/embeddings.bin` (the L4b-2 file format, one record per `features.csv` row, in the file's order) and `embeddings.json` (the run's hashes, the encoder, film and row counts, a hash of the development records, and the CPU seconds); `--look=L5` also embeds the test films and writes `look.json`. It works in two passes: the first checks the features run, every film's record, fingerprint and JPEGs, the dataset hash and the encoder before it opens a single frame (a test row without the flag stops it there); the second encodes in batches of 16 of one film's one kind of frame and writes to `embeddings.bin.partial`, and a failure deletes the run's own directory. Nothing in the server calls it.
