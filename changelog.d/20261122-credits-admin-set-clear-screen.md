### Added — set and clear an end-credits time from Admin

Library has a new End credits card with three counts (Needs a look, From Plex, Yours) and a "Review end credits…" button that opens the End credits list. The counts read again when a scan or Plex import finishes. Opening a row now has a time field, filled in with the marker or the default end-screen point: "Show stills" reloads both frames at the time you type, and "Set this time" saves it as your own. A time that is not `h:mm:ss` or `m:ss`, or that falls outside where credits can start, says so and sends nothing. On a row with your own time, "Clear my time" goes back to Plex's marker, or to none. After either, a short message confirms it, the list and counts read again and focus lands on the next row.
