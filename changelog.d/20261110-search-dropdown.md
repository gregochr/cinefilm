### Added — Search as you type in the header

The header search box now shows results as you type, from the first letter: titles, collections, actors and directors,
in that order, with the matched part of each name underlined. The first result is already selected, so Enter opens it;
the arrow keys move through all the groups, Esc clears the box (a second Esc leaves it) and clicking outside closes it.
A film, collection or person opens on its own page. When nothing matches exactly it shows close matches with a notice
("warripr" finds *Warrior*), and when some groups are cut short a "See all" link opens the Library with the same search.
It runs on your device over the search index, with no request per keystroke, and is announced to screen readers. The
Library page keeps its own box. The iPhone full-screen search follows in the next step.
