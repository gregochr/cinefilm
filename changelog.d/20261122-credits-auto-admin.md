### Added — Admin End credits: a Detected tab

Admin → Library → End credits gains a **Detected** tab, between From Plex and Yours, for the editions whose end
credits time was found automatically. Its count is on the tab and on the Library card, and its rows show the time like
the others ("Detected · 1:52:10"). The list takes `filter=auto` and the counts carry `auto`. The Clear my time hint now
reads "Goes back to Plex’s marker, the detected time, or none".
