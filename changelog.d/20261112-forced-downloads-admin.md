### Added — Admin shows downloaded subtitles, their timing and what plays

Admin → Subtitles now says where each file came from: your own file by its name, or "Downloaded from OpenSubtitles" with the release. Each row carries a quiet line with the reason playback gives for that file ("Replaced by an OpenSubtitles download that agrees"), and the file that plays is marked "Playing" in words. Beside the OpenSubtitles check it shows how the file lines up with the film's own English track, with the timing that was set automatically (for example +1.2 s) or "Timing set by you". A download can be removed with an inline confirmation (CineFilm will not use it for that edition again), and your own file, when a download has replaced it, has a "Use my file (looks right)" button. The file list can be filtered to Downloads. The dev fixtures show every state.
