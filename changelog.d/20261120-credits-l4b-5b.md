### Added — credits classifier: the model-B training entry point (L4b-5b)

Adds `CreditsTrainLrMain`, the command-line entry point of model B's training tool, run on the server like model A's. It parses `--features`, `--summary`, `--manifest`, `--embeddings` and `--out` with the optional `--l2`, `--max-iterations`, `--tolerance`, `--with-dense` and `--lit-text-variant`, prints each path it wrote, and exits 1 with a one-line message on any refusal, leaving nothing behind. `--look` is an unknown flag.
