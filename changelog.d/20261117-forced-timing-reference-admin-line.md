### Added — Admin says what a forced subtitle's timing was checked against

For a film with no English track of its own, Admin's subtitle list now shows what a forced file's timing was fitted to:
"Checked against a full English file from OpenSubtitles (the release), not yet against the film". A file whose lines
match that file reads "Lines match a full English file from OpenSubtitles" (not the green "lines up with the film's
English track", which stays for a fit to the film itself); one that does not reads "Timing needs checking", with the
reasons. It is information only: such a fit still never counts as proof or sets a timing offset.
