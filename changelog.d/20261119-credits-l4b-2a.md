### Added — credits classifier: the embeddings file format (L4b-2a)

`EmbeddingFile` writes and reads `embeddings.bin`, the binary file that holds a run's embeddings: a header (the magic `CFEMB001`, the dimension and the row count), then one record per frame with its media file id, kind (coarse or dense), offset and floats. The writer appends records and writes the row count when it is closed; the reader is a sequential cursor that refuses a wrong magic, a dimension below 1, a length that does not match the header (a truncated file or a trailing byte), an unknown kind and a NaN or infinite float.
