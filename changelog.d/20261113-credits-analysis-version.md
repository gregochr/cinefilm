### Changed — credits

The whole library is analysed again for credits with the fixes of the previous change, in the background (about 2 to 3 days, paused while anything plays). Each stored result now records which version of the analysis made it, so a later change can ask for another pass the same way. The close look at a film's credits now starts 10 seconds before the place the first pass found and covers 5 minutes (it was 3 minutes centred on that place), so credits that begin a little before the first guess are not missed. Nothing changes for playback yet.
