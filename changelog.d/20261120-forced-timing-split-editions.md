### Added — forced subtitles: the timing check now fits split editions to a stored full English file

An edition of several files with no English track in any of them (the Lord of the Rings Extended Editions) is now checked against a stored OpenSubtitles full file, as single-file editions already were, for a forced file timed for the whole edition. A per-part forced file is still checked against its own file's embedded read, and nothing is ever set or counted as proof from this check.
