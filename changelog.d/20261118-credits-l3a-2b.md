### Added — credits classifier: the CreditsFeaturesMain tool

Adds `CreditsFeaturesMain`, a throwaway-container tool that reads the development films of the credits dataset in two passes (a check, then the features) and writes `features.csv`, `frame-labels.json` and `summary.json` into a run directory of its own; test, excluded and unlabelled films are counted and never opened. Nothing in the server calls it.
