### Added — Minimum watch time for Continue watching, an In progress filter and a Last watched sort

A film now counts as in progress only once it has been watched for a minimum time (5 minutes by default, set in Admin
settings, 0 to 30 minutes); a film below it keeps its resume position but counts as unwatched, or watched if it was
watched before. Home sends at most 12 Continue watching films after the hero, plus the total. The Library gets an In
progress filter (Show) and a Last watched sort. Nothing in the screens changes yet.
