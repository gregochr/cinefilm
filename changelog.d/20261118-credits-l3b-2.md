### Added — credits classifier: CreditsTrainMain

Adds `CreditsTrainMain`, a tool run by hand in a throwaway container: it reads a features run's `features.csv` and `summary.json` and the split manifest, refuses any test row, and fits the five shipping models and the ten fold-pair models. It writes `model.json`, `oof-models.json` and `oof-logloss.json` into its own stamped directory. Nothing in the server calls it.
