### Added — credits classifier: CreditsEvaluateMain (scoring and calibration)

Adds `CreditsEvaluateMain`, the offline evaluation tool. It reads a features run and one or more training runs, scores every row of every film with the shipping segmenter code, chooses a training run and the six segmenter numbers by the nested rule, and writes `evaluation.csv` and `calibration.json` into `<out>/eval-<stamp>/`. A film of one coarse frame is scored `NOT_FOUND`. A training run made before `nested-models.json` existed, one trained on other data or another split, or rows out of order are refused with nothing written. `--look` and `--baseline` are refused until L3c-eval-2b, which adds test films, `look.json`, `summary.json` and the baseline join; a test row is refused here. Nothing in the server calls the tool.
