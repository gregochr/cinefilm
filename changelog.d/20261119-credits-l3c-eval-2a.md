### Added — credits classifier: CreditsEvaluateMain (scoring and calibration)

Adds `CreditsEvaluateMain`, the offline evaluation tool. It reads a features run and one or more training runs, scores every row of every film with the shipping segmenter code, chooses a training run and the six segmenter numbers by the nested rule, and writes `evaluation.csv` and `calibration.json` into `<out>/eval-<stamp>/`. Test films are scored only with `--look=L5`, which also writes `look.json`. A training run made before `nested-models.json` existed, one trained on other data or another split, or rows out of order are refused with nothing written. `--baseline` is refused until L3c-eval-2b, which also adds `summary.json`. Nothing in the server calls the tool.
