### Added — credits classifier: the model-B training job (L4b-5a)

Adds `CreditsTrainLrJob` and `CreditsTrainLrOptions`, the core of model B's training tool. The job reads a features run and an embeddings run, checks every embedding record against its `features.csv` row (the dropped rows too), the hashes, the feature version and a memory cap, then fits the same five shipping, ten pair and ten triple models as model A, with logistic regression on the image embeddings. It writes `model.json`, `oof-models.json`, `oof-logloss.json` and `nested-models.json` into a fresh `train-lr-<stamp>` directory, or nothing when it refuses. It has no `--look` flag and reads no test films. The command-line entry point follows in L4b-5b.
