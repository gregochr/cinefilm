### Added — backend test standards and gates

The backend build now enforces goldenhour's standards. `./mvnw clean verify` fails unless every class reaches 95% line and 90% branch coverage on its own (JaCoCo, no class excluded: the old blanket exclusions of the application class and the dev seed are gone) and the bundle stays above a floor set at the measured value, raised only; fails on any High-confidence SpotBugs or FindSecBugs finding; and fails Checkstyle on a missing Javadoc for a public type, method or constructor in `src/main` or on bad indentation. Time now comes from one injected `Clock` in the explicit application zone `Europe/London` (`cinefilm.time-zone`), the "not watched in years" rule uses that zone, and every test runs on a fixed clock at 2024-03-31T23:30Z, which is Monday morning in London, instead of the real time. Every service has its own unit test, every controller a `@WebMvcTest` slice, a route-drift test fails if any mapped `/api/**` route other than the session endpoints answers a signed-out caller, and error-body assertions check the exact message. The Actuator `container` health group (database and ping, status only) and `/actuator/info` with the git commit are added for the later Docker and deploy phases; nothing else is exposed. `docs/engineering/test-standards.md` gains the backend section and `docs/engineering/dev-and-testing.md` the build ladder.
