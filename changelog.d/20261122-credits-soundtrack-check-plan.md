### Docs — plan: a soundtrack check on automatic credits markers

A new plan, `credits-soundtrack-check-plan.md`: every automatic end-credits marker must pass a check on the film's own soundtrack (no talking well after the detected start) before it is used, measured first on the films with a Plex marker. With the check in place the test split's hold is lifted, so the editions it holds can get an automatic marker once they pass the check and a stills look. The 3c plan records the gate's result and the split's retirement, and the classifier plan points to it.
