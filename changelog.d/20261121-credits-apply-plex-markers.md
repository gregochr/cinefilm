### Added — Plex's credits markers now drive the end overlay and "watched"

Films with a Plex credits marker now show the end overlay, and count as watched, at the point where Plex says the credits start (watched at the marker). CineFilm applies the imported markers after each library scan, Plex import, Plex credits import and Edit editions save, at start-up and hourly; a marker you set yourself is never overwritten. Films already in progress and past their new marker stay in Continue watching until you resume them.
