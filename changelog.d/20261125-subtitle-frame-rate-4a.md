### Added — Admin API: retime off or on per downloaded subtitle, and the rate facts

The Admin API can now turn retime off or on for one downloaded subtitle (`PUT /api/admin/subtitles/{id}/retime`) and reports each download's frame-rate facts and a plain sentence about them (`timedFps`, `filmFps`, `retime`, `retimedBy`, `rateLine`). A choice on a file the server has not decided yet decides it at once, so the server's own fit check is then not tried. Nothing is retimed while the global `cinefilm.subtitles.retime` switch is off, except by the owner's own per-file "on" (which is refused while the switch is `restore`, the rollback, and for a file that already fits its copy as it is).
