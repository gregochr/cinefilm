### Added — weekly mutation testing

Two scheduled workflows now mutation-test the code, neither a PR gate. `pitest.yml` (Mondays 06:30 UTC, PIT with the MockMvc and full-context tests, the Testcontainers package excluded) and `stryker.yml` (Wednesdays 03:30 UTC, Stryker over the non-JSX frontend logic in `src/player`, `src/api`, `src/state` and two helpers) each run as one job, publish their HTML report and score, and open a `ci-failure` issue through `ci-failure-issue.yml` when the score drops under its floor or the run fails or is cancelled. The floors are the first measured scores rounded down and only ratchet up. Stryker's two packages are pinned to the same exact version with a Dependabot group, and `npm run test:mutation` and `./mvnw test-compile org.pitest:pitest-maven:mutationCoverage` run them locally; `dev-and-testing.md` records the scores and the rules.
