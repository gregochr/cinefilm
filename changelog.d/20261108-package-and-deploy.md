### Added — Docker image and deploy to dockermacmini

CineFilm now ships as one Docker image (React build served by Spring, with `index.html` for client routes, ffmpeg and the Intel VAAPI driver on an Ubuntu JRE) built in CI on every PR by the new `Docker — image builds` check. A `v*` tag runs `deploy.yml`: CI, push to GHCR, then `scripts/deploy.sh` on dockermacmini's own `cinefilm-prod` runner (pre-release `pg_dump`, compose `up`, smoke, optional image-only rollback with `SMOKE_ENFORCE`). `scripts/release.sh` cuts the tag, `server.forward-headers-strategy=native` makes the session cookie `Secure` behind `tailscale serve`, and `docs/engineering/operations.md` is the owner's host setup, release and rollback runbook (share only the `Movies` folder, read-only). Playwright/axe E2E, ZAP and stubbed-docker deploy tests are deferred.
