### Changed — PostgreSQL

The backend now runs on PostgreSQL 17 in the dev and prod profiles (configured through `CINEFILM_DB_URL`, `CINEFILM_DB_USER` and `CINEFILM_DB_PASSWORD`), with H2 reduced to the in-memory fast test suite. A new `integration` test package runs the migrations, the library queries and playback state against a Testcontainers Postgres 17 in CI, and the local gate excludes it because the Mac has no Docker. `docs/engineering/dev-and-testing.md` records the local Postgres setup and the expand-then-contract migration rule, and `scripts/dev-db.sh` creates the dev database.
