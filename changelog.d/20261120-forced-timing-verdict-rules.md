### Fixed — forced-file timing verdicts against a downloaded file

A forced file is now called full subtitles only when it has 300 lines or more and more than half the reference's lines, except against a reference under 600 lines, where it needs more than twice the reference's, so a genuine forced file with much foreign dialogue (The Equalizer 3) is no longer flagged. A match where nearly every line lines up but loosely (Fury, 170 ms) now says so instead of "may be another cut".
