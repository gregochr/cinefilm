### Docs — credits detection: a learned classifier (plan)

The plan for replacing the hand-written credits rules with a model learned from Plex's credits markers, with Plex as the benchmark: how the labels are built from an archive of Plex's markers taken before Plex is retired, a train/test split by film and collection, two model types compared on the same data, a start-finding step that leans late, and the phases to build it. Nothing in the app changes yet.
