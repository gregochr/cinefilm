### Added — Add any film to Christmas week from the Admin search

The Admin "Christmas films" screen has an "Add a film" search beside the tabs. It finds any film in the library and shows where it stands: TMDB keyword, Added by me, Left out by me, Keywords not fetched yet, or Not a Christmas film. One button per result adds, leaves out, puts back or removes it, with the same Undo toast, and the results stay open so several films can be added in a row. A film with no TMDB id says "Needs a match first" and opens Fix match.
