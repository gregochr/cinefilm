### Added — shared To do rules and the fields the new Admin pages read

The Admin lists now say which subtitle rows are unresolved (the owner has to act) and which are still being checked (OpenSubtitles has not been searched yet, the download scheduler would download something, or a film searched before its candidates were kept, which the next search refills), with both counts, from one shared pure class so the rail, To do and Subtitles cannot disagree. The full-need rows also carry TMDB's original language, and the attention list carries each candidate's match score and whether the best guess is confident.

A film whose forced subtitle is an embedded track now counts as playing one: it shows "Plays" instead of "None yet" and leaves the default "needed, none yet" filter and its count, which fixes an under-report. The other new fields are additive; nothing is removed or renamed.
