### Added — shared To do rules and the fields the new Admin pages read

The Admin lists now say which subtitle rows are unresolved (the owner has to act) and which are still being checked (an automatic search or download is to come), with both counts, from one shared pure class so the rail, To do and Subtitles cannot disagree. The full-need rows also carry TMDB's original language, and the attention list carries each candidate's match score and whether the best guess is confident. All changes are additive; nothing is removed or renamed.
