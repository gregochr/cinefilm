### Changed — Admin's subtitle file list is read-only, and "Looks right" moves to the film page

"Show all subtitle files" in Admin now only shows what each file is, where it sits, how it was read and whether it is playing or checked. Its per-file buttons are gone: timing is changed in the player, and everything else is done from a film's page. In a film's "Fix…" panel, a forced subtitle file you have not checked yet has "Looks right" (and an "Undo" once you have), the same check Admin had.
