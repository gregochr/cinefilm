### Added — edition-scoped OpenSubtitles search and download (Admin redesign 4b)

Two new Admin routes (backend only; the picker that uses them is 4c): `GET /api/admin/editions/{id}/opensubtitles?kind=full|forced` searches OpenSubtitles for the edition's film and ranks the results for the edition's name, and `POST /api/admin/editions/{id}/opensubtitles/download` downloads one file the owner picked from such a search (accepted for 15 minutes, for that edition and kind only). The download goes through the nightly path (the day's budget, the cap of three files per edition, removed files stay blocked), is pinned with the owner's check so the nightly plan never replaces it, and a verified download now plays before any other download. A daily limit answers 429 `OpenSubtitles daily limit reached — try again tomorrow.`; a charged download that could not be delivered is 502 and an outage 503. The routes, their shapes and every error are in the foundation plan; the dev mock API serves both.
