### Added — Full-screen search on iPhone

On a phone, the Search tab now opens a full-screen search instead of the Library page: the field at the top with a
clear button and Cancel, and the same grouped results as the desktop dropdown in larger 52px rows. Tapping a result
opens it, and Back from the film returns to where you were before searching; Cancel (or Esc) returns there too.
Enter opens the top result, and "See all" searches the Library. The Library no longer reads `?focus=search`.
